# Support

## Getting help

- **Bugs and feature requests** — open an issue in the relevant repository using
  one of the issue templates.
- **Questions and general discussion** — use the repository's **Discussions** tab
  where it is enabled, otherwise open an issue.
- **Wider context and write-ups** — the blog at [drumandbytes.com](https://drumandbytes.com/).

## What isn't supported

These are hobby projects maintained by one person in spare time. There is no SLA,
no paid support, and no private support channel for usage questions. Response
times vary.

Security reports are the exception — see [SECURITY.md](SECURITY.md) for the
private reporting process.
