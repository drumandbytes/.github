# Social preview cards

Generates 1280×640 cards so `github.com/drumandbytes/*` links unfurl as a
branded set. A repo's social preview is a GitHub **setting** (no API) — build a
card here, then upload it at `<repo> → Settings → General → Social preview`.

## Files

| | |
|---|---|
| `template.html` | The card layout (dark ground, orange accent, name + tagline, optional device). |
| `devices.min.css` | [devices.css](https://github.com/picturepan2/devices.css) v0.2.0, MIT — pure-CSS device frames. Vendored. |
| `build.sh` | Renders one card: `./build.sh <slug> "<tagline>" [none\|phone\|tablet\|laptop] [screenshot.png]` |
| `build-all.sh` | Renders every row of `cards.tsv`. |
| `cards.tsv` | `slug ⇥ device ⇥ screenshot ⇥ tagline` per repo. |
| `screenshots/` | App screenshots for the device-framed cards. |
| `out/` | Generated PNGs. |

## Requirements

- **Chromium** for the screenshot step — `build.sh` points `BROWSER` at Brave;
  override for another Chromium.
- **ImageMagick** (`magick`) only for the optional montage.

## Regenerating

```sh
./build-all.sh          # all cards
./build.sh nordvpn "…"  # just one
```

Edit taglines in `cards.tsv`. Keep them to ~1–2 lines.

## Capturing app screenshots (the device-framed cards)

Headless Chrome can't render the WebGL maps in `f1-walk` / `road-conditions-ee`.
[`shot-scraper`](https://shot-scraper.datasette.io/) (Playwright) can:

```sh
uvx shot-scraper install   # one-time

# Teesilm — wait for the map + markers to load
uvx shot-scraper "https://roadconditions.drumandbytes.ee" \
  -o screenshots/road-conditions-ee.png --width 400 --height 860 --retina --wait 12000

# f1-walk — dismiss the intro modal, then wait for the circuit map
uvx shot-scraper "https://f1walk.drumandbytes.dev/monaco" \
  -o screenshots/f1-walk.png --width 400 --height 860 --retina --wait 3000 \
  --javascript "[...document.querySelectorAll('button')].find(b=>/start the walk/i.test(b.textContent))?.click()" \
  --wait 5000
```

For static pages a plain Brave `--headless --screenshot` is enough. The
committed screenshots are downscaled JPGs (`magick shot.png -quality 82 shot.jpg`)
to keep the repo light — `build.sh` reads `.jpg` or `.png`. `stacked` derives
its two frames from `screenshots/<slug>.*` (front) and `screenshots/<slug>-back.*`
(back).

`out/` is regenerated by `build-all.sh`; the copies here are just the current set.

## Design

Deliberately minimal: repo name (Arial-bold weight), one-line tagline, the site
accent `#FF6633` as a left rule, `drumandbytes.com` wordmark. Device-framed
cards add a tilted iPhone 14 on the right for the two PWAs; everything else is
type-only so the set stays coherent. `nordvpn` / `pve-metrics-exporter` are
type-only too — people share their GHCR package, not the repo.
